# BLINDSPOT — prepared build

Double-click `start.command` on this Mac, then open http://127.0.0.1:8000. Keep the terminal open while using the app. First launch installs dependencies and needs internet access. Python 3 is required.

The app works without credentials using its source-checked local dataset. Press **Reveal connections**, inspect a company, and edit or remove holdings.

Included: app source, deployment template, fresh screenshots and check results in `artifacts/`, GitHub Actions configuration, submission copy, source review, presentation script and a captioned silent backup video in `submission/`.

Read `BUILD_STATUS.md` for actual verification and outstanding external steps. The submission draft describes only demonstrated integrations.
